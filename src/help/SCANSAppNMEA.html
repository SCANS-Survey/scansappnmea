SCANS App NMEA


If you're using the SCANS mobile phone / Android app then you can set it to collect location data on the Android device and send those data to PAMGuard through the Logger network.

Select SCANS App NMEA in the drop down list of NMEA Sources in the PAMGuard NMEA acquisition module and the NMEA data from the mobile phone will be used within PAMGuard just as though they were from a GPS connected directly to the PAMGuard computer.

Enable the 'Acquire Location' option in the SCANS App and configure the time interval between locations.
